# React Blog Project

## Description
A simple blog application built with React and Vite. The project demonstrates reusable components, props, state management, and CSS styling.

## Features
- Header with navigation links
- Blog posts displayed from static data
- Reusable React components
- Comment section with a submission form
- Responsive page layout

## Technologies
- React
- JavaScript (JSX)
- CSS
- Vite

## Running the Project
1. Open the project folder in VS Code.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.
4. Open the local URL displayed in the terminal.

## Component Structure
- Header.jsx — Displays the blog header and navigation.
- BlogPost.jsx — Displays individual blog posts.
- CommentSection.jsx — Manages comments and form submissions.
- Footer.jsx — Displays the footer.
- posts.js — Stores static blog post information.
- BlogPostPage.jsx - Page displaying a single post.
- BlogPostsPage.jsx - Page for all posts.
- CommentForm.jsx - Comment submission.
- CommentSection.jsx - Comments section with name and comment.
- ThemeContext.jsx - Light and dark mode.

## Page Navigation
- / - Home page with welcome message.
- /blog - Displays all blog posts.
- /blog/;id - Displays the idividual post.
- /contact - Contact form.

## Reacts useState useEffect
- Comment form inputs

- Contact form inputs
